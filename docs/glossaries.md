# Excel/CSV-глоссарии

В **Админка → Контекст → Корпоративные глоссарии** можно независимо вести бизнес-глоссарий, дата-глоссарий и другие справочники. Пользователю не нужно описывать контекст каждой встречи.

## Загрузка и обновление

1. Выберите «Новый глоссарий» или обновление конкретного словаря.
2. Прикрепите Excel `.xlsx` или CSV и нажмите «Проверить файл».
3. Укажите название, выберите лист Excel и сопоставьте столбцы. Первые строки доступны для просмотра. Выбранный лист и соответствие столбцов сохраняются для следующих обновлений. Если листа больше нет, показывается первый лист нового файла.
4. Нажмите «Добавить глоссарий» / «Обновить этот глоссарий». Страницу можно закрыть: очередь и прогресс сохраняются в базе.

Новая версия публикуется целиком после успешной проверки. Ошибка в последней строке не изменяет действующий словарь. Другие глоссарии и сотрудники AD сохраняются. Каждый словарь можно отдельно отключить; готовые встречи не переписываются.

| Поле | Назначение |
| --- | --- |
| Термин | Обязательное правильное написание |
| Синонимы и сокращения | Варианты для поиска через `\|`; не изменяют транскрипт |
| Разрешённые замены в транскрипте | Однозначные варианты для исправления: `труконф\|тру конф` → `TrueConf` |
| Определение | Пояснение для протокола |
| Область / подразделение | Указание области и приоритет при совпадении с подразделением пользователя из AD |

Область влияет на подбор, не на права доступа. Разрешённая замена не применяется, если вариант соответствует нескольким терминам среди включённых словарей. Синонимы и названия других терминов также учитываются при проверке неоднозначности. Одинаковые названия с разными областями могут существовать отдельно; выбранные записи сохраняют источник и версию.

Ограничения: до 30 словарей, 100 000 терминов суммарно (включая отключённые), 25 МБ на файл, 100 МБ распакованного Excel/текстовых полей на импорт, 100 столбцов. Термин/вариант — до 240 символов и 12 слов, определение — до 4000 символов, область — до 120. До 20 синонимов и 20 замен на строку. Первый ряд содержит заголовки. CSV: UTF-8 или Windows-1251; запятая, точка с запятой или табуляция. Лист Excel выбирается явно, по умолчанию первый. Формулы в выбранных полях замените значениями; `.xls` не поддерживается.

## Поиск и подбор

В админке можно искать часть термина, определения, синонима, замены или области, без учёта регистра и е/ё; несколько слов — в любом порядке. Доступны фильтр по словарю и страницы по 100 строк. Индекс FTS5/trigram обслуживает запросы от трёх символов; более короткие сокращения тоже работают, но требуют проверки текста. Кэш количества совпадений ограничен 128 запросами и инвалидируется версией.

Индекс контекста переиспользуется между встречами, один на версию в каждом процессе. После импорта рабочий процесс прогревает его. Определения остаются в SQLite и читаются только для отобранных терминов. Выбирается до 30 записей, до 1500 символов определения на запись и до 12 000 символов суммарно. Подсказки Whisper по-прежнему ограничены 500 байтами UTF-8; GigaAM использует разрешённые замены после распознавания, его акустический декодер не меняется.

Новые общие термины без упоминания не заполняют подсказки случайным алфавитным набором. Подбор использует упоминания термина/варианта в названии или транскрипте и совпадение области с подразделением пользователя. Старый общий словарь сохраняет прежнее поведение. Пользователю не требуется вводить дополнительные сведения для встречи.

## Нагрузка и хранение

Новых сервисов и моделей нет. Таблицы глоссариев и FTS5 входят в ту же `mom.db` и штатную резервную копию SQLite. Требуется SQLite с FTS5/trigram (от 3.34); создание индекса проверяется при запуске и в Docker CI.

Импорт выполняется одним рабочим потоком, порциями по 250 строк. Между порциями освобождается блокировка записи и делается пауза: 2 мс при простое, 50 мс при обработке встреч. Ошибка или обрыв не публикуют частичную версию. Зависшая после аварии задача переходит в ошибку через 120 секунд без обновления статуса; загрузку можно повторить.

Предыдущие версии сохраняют определения для уже начатых задач. После часа хранения неактивные поколения удаляются небольшими порциями, только пока нет встреч в обработке. SQLite переиспользует освобождённое место: файл базы не обязательно уменьшается физически. Предпросмотры действуют час; одновременно допускается до пяти незавершённых загрузок. Содержимое исходного файла удаляется из записи задачи после её завершения, записи терминов остаются.

Размер памяти зависит от числа терминов, синонимов, параллельных встреч и смены версий. Замеры, включая первый запрос, повторный поиск и импорт при работающем ASR: [глоссарии на CPU](../benchmarks/glossaries.md).

## Обновление существующей установки

Прежний словарь автоматически переносится в отдельный «Корпоративный словарь». Его старые варианты сохраняются как разрешённые замены. Перед обновлением сделайте резервную копию; для отката к прежней версии приложения восстановите и прежнюю базу.

Новый API: `GET /api/admin/glossaries`, `POST /api/admin/glossaries/preview`, `POST /api/admin/glossaries/import` (202), `POST /api/admin/glossaries/{id}/enabled`. Все маршруты требуют администратора. Старый `/api/admin/context/import` оставлен для совместимости: прежние лимиты сохраняются, он заменяет только исходный словарь, не затрагивая новые глоссарии.
