# Проверки фонового поиска терминов, 12 ноября 2026

Apple M1 Pro, macOS, Python 3.13. Без GPU. Использованы исключительно вымышленные встречи.

## Что проверено

25 новых серверных тестов: отделение кандидатов от действующего словаря, явное разрешение замены, отдельный выбор вариантов, ограничение подразделением, конфликты, отзыв и прежние версии, проверка дословных доказательств, исходный текст, количество разных встреч, отсутствие повторного анализа при переименовании спикера, изменение/удаление встречи во время запроса, память отклонений, откладывание, параллельные решения, атомарность при превышении лимита, расписание МСК, восстановление аренды, пауза/отмена при поступлении записи, лимит порций и продолжение, ошибки модели, HTTP-контракт настроенной модели, резервная копия, доступ только администратора, защита пути аудио, границы размера примеров.

Четыре новых теста интерфейса: выбор вариантов и правильного написания, выключенная по умолчанию замена, сохранение формы после ошибки, расписание/прогресс после повторного открытия, отзыв принятого варианта и загрузка аудио по явному действию. Полный локальный прогон: **372 серверных теста, 43 теста интерфейса**, сборка интерфейса прошла.

В браузере на отдельной тестовой базе проверены создание справочника из подтверждённых вариантов, отзыв одного варианта без удаления другого, светлая/тёмная тема, узкий/широкий экран. Проверено воспроизведение созданного тестового аудио через защищённый маршрут (MP3, 8,1 с).

## Локальная нагрузка

100 встреч × 120 реплик = **12 000 реплик**. Детерминированная заглушка выделителя возвращает точные варианты из входного текста. Измеряется реальный путь SQLite, курсоров, проверки доказательств, группировки, списка предложений и публикации справочника. Модель, сетевые задержки и пятисекундные паузы планировщика **не входят** в время.

| Проверка | Результат |
| --- | --- |
| Первый анализ, 200 порций | 11,687 с общего времени / 5,588 с CPU |
| Повторный анализ без изменений | 0,026 с; 0 обращений к модели |
| Открытие списка, медиана / p95 | 4,93 / 6,31 мс |
| Подтверждение варианта | 6,59 мс |
| Пик RSS процесса измерения | 32,6 МБ |

Память не включает ASR, модель протоколов, AD и большой корпоративный глоссарий. Это замер служебной обработки, не обещание общего времени ежедневного анализа.

В локальной среде не настроен ключ модели протоколов. **Сквозное качество выделения неизвестных терминов на реальной LLM не измерено.** Проверены контракт обращения к настроенной модели, отбрасывание отсутствующих в тексте вариантов и отсутствие автоматического применения до одобрения. В ОПЭ нужно отдельно оценить долю полезных предложений и пропусков по реальным транскриптам.

```sh
.venv/bin/python benchmarks/term_discovery_cpu.py --meetings 100 --output /tmp/terms-cpu.json
```
